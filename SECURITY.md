# Security and responsible disclosure

Vosik Signals uses Google OAuth with read-only scopes for its GA4 and GSC connectors. OAuth credential protection and data handling are described in the [Privacy Policy](https://vosiksignals.win/privacy).

**Do not disclose vulnerabilities or secrets in public GitHub issues.**

For a private security report, contact **vosikvos@gmail.com** with a description and reproduction steps. Do not send live access tokens or private analytics exports.

This repository contains documentation only, not the production server implementation.
